# Issue Tracker

- **Mode**: local markdown
- **Location**: `.scratch/<feature>/` in this repo
- **Workflow**: issues/specs live as files under `.scratch/<feature>/`; each feature directory holds its spec and tickets. No external tracker.
- **PRs as a request surface**: off
- **Triage labels**: the five canonical roles are recorded as front-matter/labels inside each markdown file (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). `to-spec` / `to-tickets` write `ready-for-agent` on publish.
