# nanobot 离线 Extras 安装说明

适用主包：`nanobot-offline-*-v0.3.5`（extras 与主包**同版本配套**）。
本包为**跨平台**（内容全为纯 Python / markdown），macOS 与 Linux 通用。
安装过程**不需要网络**。

## 前置条件

1. 已用主包完成离线安装（存在 `<prefix>/python/bin/python3` 与 `<prefix>/bin/nanobot`）。
2. `<prefix>/bin` 已在 PATH 上（主包安装时提示过）。CLI 入口靠它被找到。

## 安装

```bash
tar -xzf nanobot-extras-v0.3.5.tar.gz
cd nanobot-extras-v0.3.5

# 推荐：显式传参（最明确）
bash install-extras.sh <nanobot前缀> <workspace>

# 例如主包装在 ~/nanobot-offline、workspace 为 ~/.nanobot/workspace：
bash install-extras.sh ~/nanobot-offline ~/.nanobot/workspace

# 也可省略参数（自动探测：prefix 由 PATH 上的 nanobot 反推，workspace 取 <data>/workspace）
bash install-extras.sh
```

高级用法（等价入口）：

```bash
<prefix>/python/bin/python3 installer.py --prefix <prefix> --workspace <ws> [--dry-run] [--json]
```

`--dry-run` 只打印计划、不改动任何文件。

## 安装了什么

| 类别 | 内容 |
|---|---|
| CLI App | `dct-north-cli`、`cli-anything-asset-historical-data`（装进自带 Python）、`chart`（本地脚本） |
| 入口 | 三个 CLI 软链到 `<prefix>/bin/`（已在 PATH，便于 `run_cli_app` 解析） |
| Skill | `alert-analysis`、`dynamic-monitor`、`doc-page`、`cli-app-dct-north-cli`、`cli-app-chart`、`cli-app-cli-anything-asset-historical-data` → 装入 `<workspace>/skills/` |
| MCP | `fastgpt-knowledge` → 装入 `<数据目录>/mcp/`，并 merge 进 `config.json` 的 `tools.mcpServers` |

其余状态：CLI 登记写入 `<数据目录>/cli-apps/installed.json`（**不经过**产品自带装包流程，
以免删除/迁移 skill）。修改 `config.json` 前会自动备份为 `config.json.bak-<时间戳>`。

## 生效与重启

| 项 | 是否需重启网关 |
|---|---|
| CLI 入口（`run_cli_app`） | 否，即时可用 |
| Skill | 否，每次按需扫描 `<workspace>/skills/` |
| **MCP（fastgpt-knowledge）** | **需要**：重载 MCP 或重启网关 |

重启网关：`nanobot gateway restart`（或停止后重新启动）。

## 注意事项

- **换 workspace 要重跑**：skill 装在 `<workspace>/skills/`，换 `--workspace` 启动的实例看不到它们，
  需对新 workspace 再执行一次 `bash install-extras.sh <prefix> <新workspace>`。
- **PATH 必须保留**：CLI 入口是软链，`<prefix>/bin` 不在 PATH 会导致 `run_cli_app` 报
  "not available on PATH"。
- **可重复执行**：安装是幂等的，修复或升级时可直接重跑，不会产生重复条目。
- **`config.json` 含内部凭据**：本包内的 MCP 配置含内部 api_key，请仅在内部渠道分发。
- **失败提示**：若报 "does not look like an offline nanobot install"，说明 prefix 传错
  （该目录下没有 `python/bin/python3`）；请传主包安装目录，不要传 workspace。

## 卸载

- Skill：删 `<workspace>/skills/` 下对应 6 个目录。
- CLI：`<prefix>/python/bin/pip uninstall dct-north-cli cli-anything-asset-historical-data`，
  再删 `<prefix>/bin/` 下三个软链与 `<数据目录>/cli-apps/`。
- MCP：从 `config.json` 的 `tools.mcpServers` 移除 `fastgpt-knowledge`，删 `<数据目录>/mcp/fastgpt-knowledge/`。

## 已知限制

- 不含 `ego-browser`（独立浏览器应用，需其自身离线安装）；`dynamic-monitor` 的
  NAV 路径不依赖它，仅"Agent 独立浏览"路径不可用。
- 不含第三方 CLI App（obsidian / drawio / dify-workflow / pm2）。
- 不验证内网 API（如知识库端点）连通性——那是运行环境网络问题，与安装无关。
